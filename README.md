# 伊東 総合ポータル (ito-chamber.portal)

ふるさと納税プロトタイプとデジタルミュージアムを 1 つのリポジトリに統合したポータルです。事業者の店舗紹介ページは別リポジトリ ito-instagram で公開しています。

## 構成

- `index.html` — ポータルトップページ
- `all-in-one.html` — 全内容を 1 ページにまとめた版
- `furusato/` — ふるさと納税プロトタイプ（旧 ito_furusato.proto）
- `museum/` — デジタルミュージアム（旧 ito_digital_museum）
- 店舗紹介ページ（各展示室の「部門の事業者一覧へ」のリンク先） — 別リポジトリ [ito-instagram](https://github.com/ryo-itojournal/ito-instagram)（公開URL: https://ryo-itojournal.github.io/ito-instagram/）
- `tokens.css` — 共通スタイル

## 統合済みリポジトリ

以下のリポジトリは本リポジトリに統合済みです。

| 旧リポジトリ | 統合先 |
| --- | --- |
| ito_furusato.proto | furusato/ |
| ito_digital_museum | museum/ |
| ito_instagram | 別リポジトリ ito-instagram として再分離 |
